# Seção 5 — filas em JavaScript

`fila-array.js` mostra o custo do `shift()`; `fila.js` usa índices para manter as operações O(1); `fila-encadeada.js` implementa nós ligados. `teste-fila.js` roda as mesmas verificações com qualquer implementação; `comparar.js` mede enfileiramento e desenfileiramento.

```bash
node teste-fila.js
node comparar.js
```
